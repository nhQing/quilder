# Field SEO cho Kho dữ liệu — kế hoạch triển khai

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Kiểu field `seo` cho mọi loại nội dung, mỗi bài và mỗi ngôn ngữ một bộ, và site public đọc được hết (metadata, JSON-LD, sitemap, API, MCP).

**Architecture:** Một module thuần `src/lib/collections/seo.ts` giữ MỌI luật SEO (zod, chuẩn hoá canonical, luật ngôn ngữ, luật rơi về). Validator (`entry-data.ts`), lớp phủ (`i18n.ts`), renderer (`collection-page.ts`, `page.tsx`), sitemap, API và form đều gọi module đó, không chép luật.

**Tech Stack:** Next.js App Router, TypeScript, zod 3, Prisma/Postgres (JSONB), vitest.

**Spec:** `docs/superpowers/specs/2026-10-21-field-seo-design.md`

## Global Constraints

- Mọi chữ cho người dùng là tiếng Việt.
- Trần: `metaTitle` cảnh báo 60 / chặn 120; `metaDescription` cảnh báo 160 / chặn 300; `keywords` chặn 500; `ogImage.alt` chặn 300; `structuredData` `JSON.stringify` ≤ 20.000 ký tự. Đếm theo code point (`[...s].length`).
- Mỗi loại tối đa một field `seo`; không có trong nhóm field.
- Không có migration Prisma. Trước typecheck chạy `pnpm db:generate` (nếu `EPERM` vì server dev giữ DLL thì bỏ qua: schema không đổi).
- Thứ tự kiểm: `pnpm db:generate` → `pnpm exec tsc --noEmit -p .` → `pnpm exec eslint <file đã sửa>` → `pnpm exec vitest run <thư mục>`.
- KHÔNG commit (user chỉ commit khi yêu cầu). Cây làm việc đang có thay đổi chưa commit của việc khác — chỉ sửa đúng chỗ cần, không định dạng lại file.
- Loại không có field SEO: mọi đầu ra y hệt hôm nay.

## Review Focus

1. Bài không có khoá `seo` (mọi bài cũ) vẫn có trong sitemap — bẫy `NOT` trên JSONB. Test ở Task 5 + chạy thật trên Postgres.
2. `/en` của bài chỉ có SEO tiếng Việt: title tiếng Anh, canonical `/en/...` của chính nó, không noindex. Test ở Task 4.
3. `seo: {}` hay mọi ô toàn khoảng trắng ra đúng như bài không có SEO. Test ở Task 1.
4. Canonical `//evil.com/x` và `https://www.<site>/x`. Test ở Task 1.
5. `structuredData` chứa `</script>` không đóng được thẻ. Test ở Task 4.

**Interfaces — Produces:**
- `FieldDef` nhánh `{ t: 'seo'; key: string; label: string; help?: string }`
- `SEO_LIMITS = { titleWarn: 60, titleMax: 120, descWarn: 160, descMax: 300, keywordsMax: 500, altMax: 300, structuredMax: 20_000 }`
- `interface SeoValue { metaTitle?: string; metaDescription?: string; keywords?: string; ogImage?: { assetId: string; alt?: string }; canonicalUrl?: string; noindex?: boolean; structuredData?: Record<string, unknown> | Record<string, unknown>[] }`
- `zSeoValue(siteHost: string | null): z.ZodType<SeoValue>` — strip → transform chuẩn hoá (trim, xoá chuỗi rỗng, xoá ogImage thiếu assetId, xoá `noindex:false`) → refine trần + canonical. Câu lỗi dạng `Tiêu đề SEO dài quá 120 ký tự (đang có 134)`, `Mô tả SEO dài quá 300 ký tự (đang có N)`, `Đường dẫn chuẩn phải thuộc site này (<host>). Nhập dạng /duong-dan.`; khi `siteHost` null: `Đường dẫn chuẩn phải là đường dẫn trên site, dạng /duong-dan.`
- `normalizeCanonical(raw: string, siteHost: string | null): { ok: true; path: string } | { ok: false; error: string }` — nhận `/a?b#c`→`/a?b`; `http(s)://<host|www.host>/a`→`/a`; từ chối `//x`, giao thức khác, host lạ.
- `seoKeyOf(fields: FieldDef[]): string | null`
- `asSeo(v: unknown): SeoValue` — đọc phòng thủ JSONB thô (bỏ khoá sai kiểu), không ném.
- `localizeSeo(base: unknown, overlay: unknown): SeoValue` — luật bảng §5.2 spec: chỉ `ogImage.assetId` kế thừa bản gốc.
- `hasSeoText(v: unknown): boolean` — có metaTitle/metaDescription/keywords/ogImage.alt không rỗng.
- `interface EntrySeo { title; titleIsOverride; description; articleTitle; articleDescription; imageAssetId; imageAlt; keywords; noindex; canonical; jsonLd }` (kiểu như §6.2 spec)
- `resolveEntrySeo(shape: { titleField: string | null; fields: FieldDef[] }, data: Record<string, unknown>): EntrySeo` — thứ tự §6.3; canonical kiểm lại bằng `normalizeCanonical(…, null)` (chỉ nhận đường dẫn).
